# Grand Theft Roazhon

Jeu type GTA dans le vrai Rennes, dans le navigateur (three.js r128, aucune installation).

**Jouer :** https://agoyyaprod.github.io/GTR/

En local : `lancer_jeu.bat` (Windows) ou `./lancer_jeu.sh` (Mac/Linux), puis http://localhost:8000.
Voir `LISEZMOI.txt` pour les commandes et l'organisation du code.
